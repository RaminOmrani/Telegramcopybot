# کار کردن راحت با سرور، از ویندوز خودتان

کنسول VNC پنل هاست برای مواقع اضطراری خوب است، ولی کار کردن با آن
عذاب‌آور است: کند، بدون کپی‌پیست، و کیبورد نصفه‌نیمه.

این راهنما سه قدم دارد. بعد از آن، سرور را از ویندوز خودتان اداره
می‌کنید — با کپی‌پیست، و حتی با ویرایشگر گرافیکی.

---

## قدم ۱ — SSH را از پورت ۲۲ ببرید (یک بار، از کنسول)

مشکل فعلی این است: فیلترینگ، اتصال SSH را روی **پورت ۲۲** وسط راه
قطع می‌کند. سرور سالم است — فقط راه رسیدن به آن بسته است.

در **کنسول VNC** فقط این یک خط را تایپ کنید:

```bash
cd /opt/telkap && sudo -u telkap git pull origin main && bash deploy/ssh-port.sh
```

اسکریپت خودش فایروال را باز می‌کند، پورت `2222` را اضافه می‌کند، و
آخرش دقیقاً می‌گوید روی ویندوز چه بزنید.

> **پورت ۲۲ باز می‌ماند.** اگر پورت تازه جواب نداد، راه برگشت همیشه
> هست و از کنسول قفل نمی‌شوید.

اسکریپت **چند پورت را با هم** باز می‌کند — تا مجبور نشوید برای هر
کدام به کنسول برگردید. آخرش فهرست دستورهایی را چاپ می‌کند که باید
روی ویندوز امتحان کنید:

```
ssh -p 8443 root@82.115.8.170
ssh -p 2083 root@82.115.8.170
ssh -p 2087 root@82.115.8.170
ssh -p 2222 root@82.115.8.170
```

**هرکدام که رمز پرسید، همان درست است.**

### خطا را بخوانید — دو معنای کاملاً متفاوت دارد

| پیام | یعنی چه | چه کنید |
|---|---|---|
| `Connection refused` | یکی فعالانه RST فرستاد؛ پورت **بسته** است | فایروال شبکه‌ی هاست — بخش Firewall پنل ParsPack |
| `Connection timed out` | بسته‌ها دور ریخته می‌شوند | فیلترینگ روی خودِ پروتکل — با وی‌پی‌ان امتحان کنید |
| رمز پرسید | ✅ | همان پورت را همیشه استفاده کنید |

## قدم ۲ — دیگر رمز نزنید (کلید SSH)

هر بار تایپ کردن رمز root هم وقت‌گیر است هم ناامن. یک بار کلید
بسازید و تمام.

**روی ویندوز، در cmd:**

```cmd
ssh-keygen -t ed25519
```

سه بار `Enter` بزنید (مسیر پیش‌فرض، بدون رمز).

بعد کلید عمومی را ببینید:

```cmd
type %USERPROFILE%\.ssh\id_ed25519.pub
```

یک خط طولانی می‌دهد که با `ssh-ed25519` شروع می‌شود. **آن را کپی
کنید.**

حالا روی سرور (از همان SSH که در قدم ۱ کار کرد):

```bash
mkdir -p ~/.ssh && chmod 700 ~/.ssh
nano ~/.ssh/authorized_keys
```

خط کپی‌شده را با **راست‌کلیک** بچسبانید، بعد `Ctrl+O` → `Enter` →
`Ctrl+X`. سپس:

```bash
chmod 600 ~/.ssh/authorized_keys
```

از این پس `ssh -p 2222 root@82.115.8.170` **بدون پرسیدن رمز** وارد
می‌شود.

---

## قدم ۲.۵ — بستن ورود با رمز

**فقط بعد از اینکه `ssh bot` بدون پرسیدن رمز وارد شد.**

ورود root با رمز روی پورتی که در اینترنت باز است، هدف حمله‌ی خودکار
است — رباتی که شبانه‌روز رمز امتحان می‌کند. حالا که کلید دارید، رمز
فقط ریسک است:

```bash
ssh bot "bash /opt/telkap/deploy/ssh-harden.sh 8443"
```

اسکریپت اول مطمئن می‌شود کلیدی روی سرور هست و اگر نبود **چیزی را
عوض نمی‌کند** — بستن رمز بدون کلید یعنی بستن در به روی خودتان.

پورت‌های اضافی هم جمع می‌شوند؛ فقط ۲۲ و پورت کاری‌تان می‌مانند.

> **قفل نمی‌شوید.** این فقط ورود *از راه SSH* با رمز را می‌بندد.
> کنسول VNC پنل هاست یک ترمینال محلی است و از SSH رد نمی‌شود، پس
> همیشه با همان رمز root باز می‌شود.

---

## قدم ۳ — یک بار تایپ کردن، نه هر بار

فایل `%USERPROFILE%\.ssh\config` را بسازید (اگر نیست) و این را
داخلش بگذارید:

```
Host bot
    HostName 82.115.8.170
    User root
    Port 2222
    ServerAliveInterval 30
    ServerAliveCountMax 6
```

از این پس فقط:

```cmd
ssh bot
```

`ServerAliveInterval` مهم است: اتصال‌های بی‌کار را زنده نگه می‌دارد،
پس وسط کار قطع نمی‌شوید.

## حالا چه چیزهایی راحت می‌شود

### آپدیت، با یک خط از ویندوز

بدون اینکه حتی وارد سرور شوید:

```cmd
ssh bot "bash /opt/telkap/deploy/update.sh"
```

### دیدن لاگ زنده

```cmd
ssh bot "journalctl -u telkap -f"
```

### ویرایش فایل با ویرایشگر گرافیکی — به‌جای nano

**WinSCP** را نصب کنید ([winscp.net](https://winscp.net)). با همان
آی‌پی و پورت `2222` وصل شوید. فایل‌های سرور را مثل پوشه‌های ویندوز
می‌بینید و با دابل‌کلیک در Notepad باز و ویرایش می‌کنید.

مخصوصاً برای `.env` عالی است.

### یا کل پروژه در VS Code

افزونه‌ی **Remote - SSH** را نصب کنید، `Ctrl+Shift+P` →
`Remote-SSH: Connect to Host` → `bot`. کل `/opt/telkap` مثل یک
پروژه‌ی محلی باز می‌شود — با رنگ‌بندی، جست‌وجو و ترمینال.

این راحت‌ترین حالت ممکن است.

## دو نکته‌ی کوچک که آزار می‌دهند

**۱) `systemctl status` صفحه را قفل می‌کند.**
خروجی داخل یک صفحه‌خوان باز می‌شود و هر چه تایپ کنید، آن می‌بلعد.
همیشه `--no-pager` بزنید:

```bash
systemctl status telkap --no-pager
```

اگر گیر افتادید: `q` بزنید.

**۲) موقع تایپ رمز هیچ چیز روی صفحه نمی‌آید.**
نه ستاره، نه نقطه. این عمدی است. تایپ کنید و `Enter` بزنید.

**۳) فارسی به‌صورت مربع دیده می‌شود (`▯▯▯▯`).**
فونت پیش‌فرض `cmd.exe` حروف فارسی ندارد. راه‌حلش عوض کردن برنامه است،
نه تنظیمات:

**Windows Terminal** را نصب کنید — از Microsoft Store، رایگان. هم فارسی
را درست نشان می‌دهد، هم رنگ‌ها را، هم تب دارد و هم کپی‌پیست راحت‌تری.
همه‌ی دستورهای این راهنما داخلش عیناً کار می‌کنند.

اگر نمی‌خواهید چیزی نصب کنید، در همان cmd راست‌کلیک روی نوار عنوان →
Properties → Font → **Consolas** یا **Lucida Console**. بهتر می‌شود ولی
کامل نه.

## از یک کامپیوتر تازه، بدون کلید

اگر روی کامپیوتر دیگری هستید و کلید SSH را ندارید، این نشانه‌ها را
می‌بینید:

```
ssh -p 2222 root@82.115.8.170     →  Connection timed out
ssh -p 8443 root@82.115.8.170     →  رمز می‌پرسد، ولی هر رمزی رد می‌شود
                                     Permission denied (publickey,password)
```

**این خرابی نیست؛ دقیقاً همان چیزی است که «قدم ۲.۵» ساخته.** پورت
۲۲۲۲ بسته شده چون فقط ۲۲ و پورتِ انتخابی باز مانده‌اند، و رمزِ root
پذیرفته نمی‌شود چون `PermitRootLogin prohibit-password` است. sshd
هنوز رمز را <b>می‌پرسد</b> ولی هیچ‌وقت قبول نمی‌کند — و همین گمراه‌کننده
است.

هیچ رمزی این را باز نمی‌کند. دو راه دارید:

### راه ۱ — کنسول VNC پنل هاست (ساده‌ترین)

کنسول یک ترمینال محلی است و از SSH رد نمی‌شود، پس همیشه با رمز root
باز می‌شود. کارتان را همان‌جا انجام بدهید:

```bash
cd /opt/telkap
bash deploy/update.sh
```

### راه ۲ — کلیدِ این کامپیوتر را اضافه کنید

روی ویندوز:

```cmd
ssh-keygen -t ed25519 -C "%COMPUTERNAME%"
type %USERPROFILE%\.ssh\id_ed25519.pub
```

آن یک خط را کپی کنید و در کنسول VNC:

```bash
mkdir -p /root/.ssh && chmod 700 /root/.ssh
nano /root/.ssh/authorized_keys      # در خط تازه بچسبانید
chmod 600 /root/.ssh/authorized_keys
```

بعد از ویندوز: `ssh -p 8443 root@82.115.8.170`

> **کلید خصوصی (`id_ed25519` بدون `.pub`) را از کامپیوتر قبلی
> ایمیل نکنید، در تلگرام نفرستید و در گیت‌هاب نگذارید.** ساختن یک
> کلید تازه ارزان‌تر و امن‌تر از جابه‌جا کردن کلید قدیمی است.

### و اگر رمزِ root را هم ندارید

از پنل هاست عوضش کنید (Reset root password)، بعد کنسول VNC.

---

## اگر همه‌ی پورت‌ها بسته بودند

یعنی فیلترینگ روی **پروتکل** است نه پورت. آن‌وقت:

- وی‌پی‌ان را روشن کنید و دوباره `ssh bot` بزنید
- یا سرور دیگری از همان پنل امتحان کنید
- کنسول VNC همیشه به‌عنوان راه آخر هست

خبر خوب: ربات خودش هیچ‌وقت این مشکل را ندارد — سرور در سوئد است و
اتصالش به تلگرام مستقیم و بی‌واسطه است. این فقط مشکلِ **دسترسی
شما** به سرور است، نه مشکل سرویس.
