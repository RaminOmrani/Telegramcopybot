# بالا آوردن نسخه‌ی تازه — از صفر تا صد

سرور شما **لینوکس** است (اوبونتو، در سوئد) ولی کامپیوتر خودتان
**ویندوز**. پس اول باید از ویندوز به سرور وصل شوید، بعد دستور را
آنجا بزنید. کل ماجرا سه مرحله است و کمتر از یک دقیقه طول می‌کشد.

---

## مرحله ۱ — باز کردن CMD در ویندوز

کلید <kbd>Windows</kbd> را بزنید، بنویسید `cmd`، اینتر.

> PowerShell و Windows Terminal هم دقیقاً همین‌طور کار می‌کنند. فرقی
> ندارد کدام را باز کنید.

---

## مرحله ۲ — وصل شدن به سرور

```
ssh root@82.115.8.170
```

رمز root سرور را می‌خواهد. **بنویسیدش و اینتر بزنید — نگران نباشید که
چیزی روی صفحه نمی‌آید.** لینوکس موقع تایپ رمز هیچ ستاره‌ای هم نشان
نمی‌دهد؛ این عمدی است، نه اینکه کیبورد کار نکند.

اولین باری که وصل می‌شوید یک سؤال می‌پرسد:

```
Are you sure you want to continue connecting (yes/no)?
```

`yes` بنویسید و اینتر. این فقط یک بار پرسیده می‌شود.

وقتی وصل شدید، ابتدای خط عوض می‌شود به چیزی شبیه این:

```
root@ubuntu-4gb-hel1-1:~#
```

**از این لحظه، هر چه تایپ کنید روی سرور اجرا می‌شود، نه روی ویندوز
شما.**

---

## مرحله ۳ — یک دستور

```bash
sudo bash /opt/telkap/deploy/update.sh
```

تمام. اسکریپت بقیه‌اش را خودش انجام می‌دهد و آخرش یکی از این دو را
می‌گوید:

```
✓ نسخه‌ی تازه بالا آمد.
```

یا اگر چیزی خراب بود:

```
✗ ربات با نسخه‌ی تازه بالا نیامد. برمی‌گردم به نسخه‌ی قبلی.
```

در حالت دوم، **خودش برگشته و ربات دوباره کار می‌کند** — لاگ خطا را هم
چاپ می‌کند. همان را کپی کنید و برایم بفرستید.

---

## فقط برای اولین بار

فایل `update.sh` تازه ساخته شده، پس هنوز روی سرور نیست. یک بار این را
بزنید تا بیاید:

```bash
cd /opt/telkap && sudo -u telkap git pull origin main
```

از دفعه‌ی بعد فقط همان یک دستور مرحله‌ی ۳ کافی است.

---

## خلاصه — هر بار که می‌گویم «آپدیت کن»

```
# ۱. در ویندوز: cmd را باز کنید
ssh root@82.115.8.170
# رمز را بزنید

# ۲. روی سرور:
sudo bash /opt/telkap/deploy/update.sh

# ۳. بستن اتصال:
exit
```

---

## چیزهایی که ممکن است ببینید

| پیام | یعنی چه | چه کنید |
|---|---|---|
| `همین حالا آخرین نسخه است` | چیزی برای گرفتن نبود | هیچی، تمام است |
| `روی سرور تغییر ذخیره‌نشده هست` | فایلی روی سرور دستی عوض شده | به من بگویید |
| `Permission denied` بعد از رمز | رمز اشتباه بود | دوباره امتحان کنید |
| `Connection timed out` | سرور جواب نمی‌دهد | چند دقیقه بعد، یا پنل ParsPack را ببینید |
| `✗ نسخه‌ی قبلی هم بالا نیامد` | مشکل از کد نیست — شبکه یا `.env` | لاگ را برایم بفرستید |

---

## دیدن اینکه ربات چه می‌کند

```bash
systemctl status telkap        # الان روشن است یا نه
journalctl -u telkap -f        # لاگ زنده — با Ctrl+C بیرون بیایید
journalctl -u telkap -n 50     # ۵۰ خط آخر
```

---

## دو چیزی که هرگز نباید بکنید

**۱. فایل `.env` را دستی پاک یا جایگزین نکنید.**
`FERNET_KEY` داخل آن است. اگر برود، سشن ورود **همه‌ی** کاربران
غیرقابل رمزگشایی می‌شود و همه باید دوباره اکانتشان را وصل کنند.
مخصوصاً هیچ‌وقت `.env.example` را روی `.env` کپی نکنید.

**۲. پوشه‌ی `data/` را پاک نکنید.**
دیتابیس، سشن‌ها و پرداخت‌ها آنجاست. اسکریپت پیش از هر به‌روزرسانی
خودش پشتیبان می‌گیرد و ده نسخه‌ی آخر را در `data/backups/` نگه
می‌دارد.

---

## اگر SSH نصب نیست

ویندوز ۱۰ و ۱۱ خودشان `ssh` را دارند و کاری لازم نیست. اگر پیام
`'ssh' is not recognized` دیدید:

**Settings → Apps → Optional features → Add a feature → OpenSSH Client**

یا اگر ترجیح می‌دهید برنامه‌ی گرافیکی داشته باشید، **PuTTY** را نصب
کنید و در فیلد Host Name بنویسید `82.115.8.170`، پورت `22`.
