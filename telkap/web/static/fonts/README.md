# فونت وزیرمتن

چهار وزنِ مورد استفاده‌ی پنل، از نسخه‌ی رسمی
[rastikerdar/vazirmatn](https://github.com/rastikerdar/vazirmatn) v33.003.

## چرا در خودِ پروژه است، نه از CDN

پنل و صفحه‌ی فروش را کاربر ایرانی باز می‌کند. فونتی که از CDN خارجی
بیاید یا کند می‌آید یا اصلاً نمی‌آید — و صفحه‌ای که فونتش نیامده، با
فونت پیش‌فرضِ ویندوز رندر می‌شود که برای فارسی بد است. ۲۰۰ کیلوبایت
در خودِ سرور، این ریسک را کامل حذف می‌کند.
